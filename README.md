# Validador de Contraseñas

Proyecto final de Lógica de Programación II.

Aplicación desarrollada en Python utilizando Programación Orientada a Objetos (POO).

## Funcionalidades
- Interfaz gráfica interactiva (GUI).
- Validación de contraseñas.
- Generación y verificación de hash PBKDF2-HMAC-SHA256.
- Cifrado y descifrado AES-GCM.
- Análisis de complejidad algorítmica.
- Monitoreo de CPU y memoria RAM mediante gráficas.
- Investigación sobre computación cuántica y ciberseguridad.

## Tecnologías
- Python
- Tkinter
- Matplotlib
- Psutil
- Cryptography

## Instalación
pip install -r requirements.txt


## Ejecución
python Validador_Contrasenas_GUI_POO.py
